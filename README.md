# Sistema de Gestión de Vehículos

## Descripción
Este proyecto consiste en un sistema desarrollado en Java que permite representar diferentes tipos de vehículos mediante el uso de programación orientada a objetos.

## Objetivo
Aplicar el concepto de herencia en Java para reutilizar atributos y métodos de una clase principal en diferentes clases derivadas.

## Estructura del proyecto

- **Vehiculo:** Clase padre que contiene los atributos marca, modelo y año.
- **Automovil:** Clase hija que hereda de Vehiculo y agrega el número de puertas.
- **Motocicleta:** Clase hija que hereda de Vehiculo y agrega la cilindrada.
- **Main:** Clase principal que ejecuta el programa.

## Conceptos aplicados
- Herencia.
- Encapsulamiento.
- Constructores.
- Uso de super().
- Sobrescritura de métodos (@Override).
- Programación orientada a objetos.

## Lenguaje utilizado
Java.
